## 三、核心代码

### 3.1 FilePreviewService — kkFileView URL 构建服务

**文件路径：** `src/main/java/com/example/fileupload/service/FilePreviewService.java`

**职责：** 根据文件 ID 构建 kkFileView 完整预览 URL。

```java
package com.example.fileupload.service;

import com.example.fileupload.model.FileInfo;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;

import java.io.UnsupportedEncodingException;
import java.net.URLEncoder;
import java.nio.charset.StandardCharsets;
import java.util.Base64;

@Service
public class FilePreviewService {

    private static final Logger log = LoggerFactory.getLogger(FilePreviewService.class);

    private final FileStorageService fileStorageService;

    @Value("${preview.kk-file-view.server-address:http://127.0.0.1:8012}")
    private String kkFileViewServer;

    @Value("${preview.kk-file-view.watermark-txt:}")
    private String watermarkTxt;

    @Value("${preview.app-base-url:http://127.0.0.1:8080}")
    private String appBaseUrl;

    public FilePreviewService(FileStorageService fileStorageService) {
        this.fileStorageService = fileStorageService;
    }

    /**
     * 根据文件 ID 生成 kkFileView 在线预览 URL
     * URL 格式：{kkFileView}/onlinePreview?url={Base64(previewFileUrl)}&watermarkTxt=xxx
     */
    public String generatePreviewUrl(String id) {
        FileInfo fileInfo = fileStorageService.findById(id)
                .orElseThrow(() -> new IllegalArgumentException("文件不存在: " + id));

        // 1. 构建供 kkFileView 拉取的文件流地址
        String previewFileUrl = buildPreviewFileUrl(fileInfo);

        // 2. Base64 编码
        String encodedUrl = Base64.getEncoder().encodeToString(
                previewFileUrl.getBytes(StandardCharsets.UTF_8));

        // 3. 拼接 kkFileView 预览 URL
        StringBuilder sb = new StringBuilder();
        sb.append(normalizeServerAddress())
                .append("/onlinePreview?url=")
                .append(encodeUrl(encodedUrl));

        // 4. 附加水印参数
        if (watermarkTxt != null && !watermarkTxt.isEmpty()) {
            sb.append("&watermarkTxt=").append(encodeUrl(watermarkTxt));
        }

        return sb.toString();
    }

    private String buildPreviewFileUrl(FileInfo fileInfo) {
        String base = normalizeBaseUrl(appBaseUrl);
        return base + "/api/files/previewFile"
                + "?fileKey=" + encodeUrl(fileInfo.getFileKey())
                + "&uploadType=" + encodeUrl(fileInfo.getStorageType())
                + "&fullfilename=" + encodeUrl(fileInfo.getOriginalFilename());
    }

    // ... normalize / encode 辅助方法省略
}
```

**关键设计点：**
- `fullfilename` 参数确保 kkFileView 能正确识别文件类型（即使下载流 URL 本身没有后缀）
- Base64 编码是 kkFileView 的标准要求，避免 URL 中的特殊字符导致解析失败
- 水印参数可选，配置为空时不拼接

### 3.2 FileController — 新增预览端点

#### 端点 1：获取预览 URL

```java
/**
 * GET /api/files/previewUrl?id=xxx
 *
 * 生成 kkFileView 在线预览 URL。
 * 前端拿到该 URL 后 window.open() 即可在浏览器中预览文件。
 */
@GetMapping("/previewUrl")
public Result<String> previewUrl(@RequestParam("id") String id) {
    try {
        String previewUrl = previewService.generatePreviewUrl(id);
        return Result.success(previewUrl);
    } catch (IllegalArgumentException e) {
        return Result.error(404, e.getMessage());
    } catch (Exception e) {
        log.error("Generate preview URL failed, id={}", id, e);
        return Result.error(500, "生成预览链接失败: " + e.getMessage());
    }
}
```

#### 端点 2：文件流提供（供 kkFileView 拉取）

```java
/**
 * GET /api/files/previewFile?fileKey=xxx&uploadType=local&fullfilename=report.pdf
 *
 * 供 kkFileView 服务器拉取文件流的端点。
 * 与 download 接口的区别：
 * - Content-Disposition 为 inline（浏览器内展示而非下载）
 * - Content-Type 根据文件后缀动态设置
 * - 通过 fullfilename 参数确保 kkFileView 能正确识别无后缀的下载流
 */
@GetMapping("/previewFile")
public ResponseEntity<byte[]> previewFile(
        @RequestParam("fileKey") String fileKey,
        @RequestParam("uploadType") String uploadTypeCode,
        @RequestParam(value = "fullfilename", required = false) String fullFilename) {
    try {
        UploadType uploadType = UploadType.fromCode(uploadTypeCode);
        byte[] data = processor.download(uploadType, fileKey);
        if (data == null || data.length == 0) {
            return ResponseEntity.status(HttpStatus.NOT_FOUND).build();
        }

        String originalFilename = resolveOriginalFilename(fileKey, uploadTypeCode, fullFilename);

        HttpHeaders headers = new HttpHeaders();
        headers.setContentDisposition(
                ContentDisposition.inline()
                        .filename(originalFilename, StandardCharsets.UTF_8)
                        .build()
        );
        headers.setContentType(resolveContentType(originalFilename));
        headers.setContentLength(data.length);

        return ResponseEntity.ok().headers(headers).body(data);
    } catch (Exception e) {
        log.error("File preview failed", e);
        return ResponseEntity.internalServerError().build();
    }
}
```

#### 辅助方法：Content-Type 动态解析

```java
/**
 * 根据文件后缀返回对应的 Content-Type（覆盖 20+ 种常见格式）
 */
private MediaType resolveContentType(String filename) {
    if (filename == null) return MediaType.APPLICATION_OCTET_STREAM;
    String lower = filename.toLowerCase();
    if (lower.endsWith(".pdf"))  return MediaType.APPLICATION_PDF;
    if (lower.endsWith(".png"))  return MediaType.IMAGE_PNG;
    if (lower.endsWith(".jpg") || lower.endsWith(".jpeg")) return MediaType.IMAGE_JPEG;
    if (lower.endsWith(".gif"))  return MediaType.IMAGE_GIF;
    if (lower.endsWith(".bmp"))  return MediaType.parseMediaType("image/bmp");
    if (lower.endsWith(".txt"))  return MediaType.TEXT_PLAIN;
    if (lower.endsWith(".doc"))  return MediaType.parseMediaType("application/msword");
    if (lower.endsWith(".docx")) return MediaType.parseMediaType(
        "application/vnd.openxmlformats-officedocument.wordprocessingml.document");
    if (lower.endsWith(".xls"))  return MediaType.parseMediaType("application/vnd.ms-excel");
    if (lower.endsWith(".xlsx")) return MediaType.parseMediaType(
        "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet");
    if (lower.endsWith(".ppt"))  return MediaType.parseMediaType("application/vnd.ms-powerpoint");
    if (lower.endsWith(".pptx")) return MediaType.parseMediaType(
        "application/vnd.openxmlformats-officedocument.presentationml.presentation");
    if (lower.endsWith(".zip"))  return MediaType.parseMediaType("application/zip");
    if (lower.endsWith(".mp4"))  return MediaType.parseMediaType("video/mp4");
    // ... 更多格式
    return MediaType.APPLICATION_OCTET_STREAM;
}
```

## 四、previewFile vs download 接口对比

| 维度 | `/api/files/download` | `/api/files/previewFile` |
|------|----------------------|--------------------------|
| **用途** | 用户下载文件 | kkFileView 拉取文件流进行预览转换 |
| **Content-Disposition** | `attachment`（触发浏览器下载） | `inline`（浏览器内展示） |
| **Content-Type** | 固定 `application/octet-stream` | 按文件后缀动态解析（20+ 种 MIME） |
| **fullfilename 参数** | 不支持 | 支持（确保 kkFileView 识别无后缀流） |
| **调用方** | 前端/用户 | kkFileView 服务器 |
| **路由逻辑** | 通过策略模式路由到对应存储 | 复用 `RequestUploadProcessor.download()` |

**设计决策：** 为什么不修改 download 接口？
- download 的 `attachment` 语义是面向用户的下载行为，不应改变
- previewFile 需要 `inline` + 精确 Content-Type，语义完全不同
- 分离端点避免引入条件分支，保持单一职责

## 五、使用示例

### 5.1 后端 API 调用

```bash
# 1. 先上传文件（假设得到 id=a1b2c3d4）
curl -X POST "http://localhost:8080/api/files/upload?uploadType=local" \
  -F "file=@report.pdf"

# 2. 获取预览 URL
curl "http://localhost:8080/api/files/previewUrl?id=a1b2c3d4"
```

**响应示例：**
```json
{
  "code": 200,
  "message": "success",
  "data": "http://127.0.0.1:8012/onlinePreview?url=aHR0cDovLzEyNy4wLjAuMTo4MDgwL2FwaS9maWxlcy9wcmV2aWV3RmlsZT9maWxlS2V5PWExYjJjM2Q0JnVwbG9hZFR5cGU9bG9jYWwmZnVsbGZpbGVuYW1lPXJlcG9ydC5wZGY="
}
```

### 5.2 前端调用

```html
<!-- 方式一：新窗口打开 -->
<button onclick="previewFile('a1b2c3d4')">预览文件</button>

<script>
function previewFile(fileId) {
    fetch('/api/files/previewUrl?id=' + fileId)
        .then(res => res.json())
        .then(result => {
            if (result.code === 200) {
                window.open(result.data, '_blank');
            } else {
                alert('预览失败: ' + result.message);
            }
        });
}
</script>
```

```html
<!-- 方式二：iframe 嵌入 -->
<iframe id="preview-frame" width="100%" height="600px"></iframe>

<script>
function embedPreview(fileId) {
    fetch('/api/files/previewUrl?id=' + fileId)
        .then(res => res.json())
        .then(result => {
            if (result.code === 200) {
                document.getElementById('preview-frame').src = result.data;
            }
        });
}
</script>
```

### 5.3 直接访问 previewFile 端点

```bash
# kkFileView 内部会调用此端点拉取文件流

# 响应头示例：
# Content-Disposition: inline; filename="report.pdf"; filename*=UTF-8''report.pdf
```
